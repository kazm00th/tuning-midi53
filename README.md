# 53平均律で純正に鳴る MIDI 鍵盤（tuning-midi53）

MIDI 鍵盤か PC のキーボードで 12 平均律の鍵を弾くと、その和音を 53 平均律の段で純正に鳴らすブラウザのアプリです。共通音を押したまま和音を移っていくと、純正律と同じく全体が少しずつずれていきます（たとえば Ⅰ–Ⅵ–Ⅱ–Ⅴ–Ⅰ で 1 段 = 22.6¢ 下がる）。いわゆる適応純正律（adaptive just intonation）を、53 平均律の段で行います。依存ライブラリなし、ビルドなしの HTML と JavaScript だけでできています。

## 使い方

`index.html` を開き、「音を出す」を押します（ブラウザの決まりで、音を出すには最初に一度操作が要ります）。MIDI を使うには、Web MIDI に対応したブラウザ（Chrome・Edge など）で、https か localhost から開いてください。

- **MIDI 入力**：つないだ装置を選びます。すべてのチャンネルを 1 つにまとめて扱い、ベロシティで音量が変わります。サステインペダル（CC64）を踏んでいるあいだは、離した鍵も押したままとみなします。
- **PC のキーボード**：`A S D F G H J K L` が白鍵（C D E F G A B C D）、`W E T Y U O P` が黒鍵、`Z`／`X` でオクターブを下げる／上げる（C1〜C7、最初は C4）、`Space` がペダル。
- **共通音が無いときの置き直し**：鳴っている音が無い状態から押した和音を、12 平均律に近い位置に置きます。「根音を 12 平均律に合わせる」か「和音全体で均す」（ずれの二乗の和が最小）を選べます。無音から最初の鍵を押してから 30 ms のあいだに押した鍵を、1 つの和音として扱います。
- **あとから合わなくなった音**：あとから押した音で和音が決まり、すでに鳴っている音が純正な位置からずれていると分かったとき、「動かして純正にする」か「動かさない」を選べます。例：C → D → F → A と押すと、D 短七として D は 9 段から 8 段へ動きます（動かさないなら 9 段のまま）。
- **基準 A4**：12 平均律の A4 の周波数（既定 440 Hz）。53 平均律の段 0 は 12 平均律の C4 と同じ高さです。
- **ずれをリセット**：次に押す和音を、鳴っている音を無視して 12 平均律に近い位置に置き直します。
- **表示**：A 鳴っている音（音名・段・12 平均律からのずれ・役割・共通音）、B 鍵盤、C 格子と根音の道、D 53 段の円。それぞれ表示・非表示を選べます。音名は篠原 2019 と同じ書き方で、右肩の数はシントニック・コンマの指数、(7) は 7 倍音（7/4）です。

## 音の置き方

- 鳴っている音があるとき、新しい音は、鳴っている音に対していちばん単純な純正の比になる段に置き、鳴っている音は動かしません。音程は、短二度 16/15（5 段）、長二度 9/8（9）、短三度 6/5（14）、長三度 5/4（17）、完全四度 4/3（22）、増四度 45/32（26）、完全五度 3/2（31）、短六度 8/5（36）、長六度 5/3（39）、短七度 16/9（44）、長七度 15/8（48）。
- 認識する和音とその純正な形：長三和音、短三和音、属七（短七度は 7/4、43 段）、短七（短七度は 9/5、45 段）。
- 7 倍音の音は、ほかの音が鳴っていれば次の音の基準にしません。
- 共通音を押したまま和音を移ると、純正律と同じく全体がずれていきます。すべて離すと、次の和音は 12 平均律に近い位置へ戻ります。

## 音

16 倍音までの のこぎり波を模した加算合成。鍵を押しているあいだ一定の音量で鳴り、立ち上がりと立ち下がりは 10 ms。同時に鳴らせる音は 24 まで（超えるといちばん古い音を止めます）。出口のリミッターの先読みのため、音は鍵を押してから約 6 ms 遅れて出ます。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | 画面 |
| `tuning53.js` | 格子・53 平均律の段・音名・和音の認識・12 平均律に近い位置 |
| `engine.js` | 鍵の出来事から各音の位置を決める（30 ms のまとまり、ペダル、和音の手直し、リセット） |
| `voices.js` | Web Audio（発振器・10 ms の変化・リミッター） |
| `input.js` | MIDI の解釈と PC のキーボードの配置 |
| `views.js` | 4 つの表示 |
| `app.js` | つなぎ |
| `tests/` | `node --test` のテスト |

## テスト

node --test --test-isolation=none tests/*.test.js
